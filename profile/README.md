## 📘 What Is the Benefit Plan Standard?

The **Benefit Plan Standard (BPS)** is the first unified, open, machine-readable schema for representing medical benefit plans across U.S. healthcare carriers.

It provides:

- A **canonical JSON schema** for benefit plan normalization  
- Standard terminology and field definitions  
- Carrier crosswalk tables  
- Validation rules & ingestion guidance  
- Extensible modules for pharmacy, behavioral health, dental/vision, and more  
- AI-ready structure for automation, analytics, and interoperability  

The goal:  
**A single, consistent representation of health plan benefits across all carriers.**

## 🎯 Mission

To create an **interoperable, open, regulator-friendly standard** for benefit plan data that enables:

- AI-driven document ingestion  
- Accurate plan comparison  
- Automated benefit verification  
- Broker and TPA data pipelines  
- Compliance transparency  
- Carrier interoperability  

---

## 🧩 Why This Standard Matters

Today, every carrier describes benefit plans differently.  
BPS solves this by providing:

- **Consistency** — common fields across all carriers  
- **Traceability** — every value linked back to its source snippet  
- **Accuracy** — schema validation + semantic validation  
- **Automation** — AI ingestion pipelines  
- **Open governance** — contributions from industry stakeholders
